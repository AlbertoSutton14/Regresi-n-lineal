El Github numero 1 trata sobre el teormea de limite central y sobre como las muestras sacadas de una población tienden a una distribución normal. Entre mas muestras mas exacta.

El Github numero 2 trata sobre una regresión lineal multivariable con 20,000 simulaciones. Usamos el metodo de MCO y residuales.

EL Github numero 3 trata sobre una regresión lineal simple.

EL protyecto final econometria trata sobre una regresión lineal multivariable en la que respondemos la pregunta de si los minutos jugados realmente se relacionan con los puntos anotados. Usamos las siguientes variables: minutos jugados, asistencias, bloqueos, robos, perdidad, rebotes defensivos, rebotes ofensivos, win rate y fouls personales.
